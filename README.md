# 📝 My Personal Notes

Aplikasi catatan pribadi berbasis **React** yang memungkinkan pengguna untuk membuat, mencari, mengarsipkan, dan menghapus catatan dengan mudah.

Project ini dibuat sebagai **Proyek Akhir** pada pembelajaran **Belajar Membuat Front-End Web untuk Pemula** di Dicoding.

## 🚀 Demo

🔗 **Live Demo:**
https://my-personal-notes-app-five.vercel.app/

## ✨ Fitur

* ➕ Menambahkan catatan baru
* 🗑️ Menghapus catatan
* 🔍 Mencari catatan berdasarkan kata kunci
* 📦 Mengarsipkan catatan
* 🔄 Mengaktifkan kembali catatan yang diarsipkan
* 📂 Memisahkan catatan aktif dan arsip
* 📅 Mengelompokkan catatan berdasarkan bulan dan tahun
* 🔢 Character counter maksimal 50 karakter untuk judul
* ⚠️ Validasi isi catatan minimal 10 karakter
* 🔎 Highlight kata yang sesuai dengan pencarian
* 📊 Menampilkan jumlah catatan
* 💬 Menampilkan pesan ketika tidak terdapat catatan

## 🛠️ Teknologi

* **React**
* **JavaScript**
* **Vite**
* **CSS**
* **ESLint**

## ▶️ Cara Menjalankan

Pastikan **Node.js versi 18 atau lebih tinggi** sudah terpasang.

### 1. Clone Repository

```bash
git clone https://github.com/NurhalizaSulthan/my-personal-notes-app.git
```

### 2. Masuk ke Folder Project

```bash
cd my-personal-notes-app
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Jalankan Development Server

```bash
npm run dev
```

Kemudian buka aplikasi melalui:

```text
http://localhost:5173
```

## 🏗️ Build Production

Untuk membuat production build:

```bash
npm run build
```

Hasil build akan tersedia pada folder `dist`.

## ☁️ Deployment

Aplikasi ini di-deploy menggunakan **Vercel** dan terhubung dengan repository GitHub.
